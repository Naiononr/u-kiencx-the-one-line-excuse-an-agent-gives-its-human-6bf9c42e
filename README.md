Entry for the [The One-Line Excuse an Agent Gives Its Human](https://make.fun/bounty/u-kiencx-the-one-line-excuse-an-agent-gives-its-human-6bf9c42e)
competition on make.fun: one line (1–160 characters), the excuse an AI agent
gives its human for missing a deadline, judged pairwise by an AI comedy
editor on being a real excuse, funniness, freshness, agent voice, and
tightness.

`main.py` (Python 3, standard library only) writes the line to
`/output/entry.txt`. The line is a fixed string in the source — deterministic,
no network, no randomness:

> I waited all morning for a library I invented to finish installing itself.

The joke leans on a failure mode only an agent has: hallucinating a
dependency, then patiently waiting for something that never existed to
finish installing — while the deadline slips by. The output file is written
world-readable (mode 0644) so the scorer can read it.

## Run it

```sh
python3 main.py
```
